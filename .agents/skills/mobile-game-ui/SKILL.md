# 《孤军》手机交互

先读 AGENTS.md 与 UI-DESIGN.md。触控、文本和真实状态优先，不能用“精简”隐藏关键代价。

## 布局契约

- 320像素宽度可用；页面自身不横向溢出。短屏与横屏必须能到达输入、发送、取消、保存和全部事件选择。
- 选关的开始／继续入口固定在可见的操作区，内容区单独滚动。固定区不得遮挡最后一项；当前章节、已选战术与“继续沿用档内选择”要明确。
- 游戏按战况、记录、命令三层组织。保留可滚动的阅读区，不让教学、工具条、战术状态抢占整个屏幕。
- 手机输入非空时沿用项目已有收起快捷区的规则；长预览限制高度并可滚动。真实虚拟键盘与浏览器视口模拟是不同证据，不能混称实机通过。
- 短屏允许工具区自身滚动，不能靠裁切或藏掉发送按钮处理。主要按钮与关闭入口尽量至少44×44 CSS像素；WCAG2.2 AA的24像素目标要求与项目44像素目标分别描述。
- 资源名称、数量、时间和风险完整可读；重要库存不依赖未提示的横向滚动。必要时一组控件单独横滑，并给可见的“横滑查看”提示。
- 正文通常16px、行高1.75以上；辅助标签通常12px。宋体用在叙事，无衬线用于小字控制；不能强制远程字体破坏免费、离线体验。
- 普通文字对比度目标4.5:1，大字3:1。危险同时有文字或符号，不能只靠红绿区分。禁用原因保留可读，不把整段说明降到几乎不可见。
- 键盘焦点清楚可见，遵守减少动态效果偏好；高频界面不循环闪光。

## 取舍

逐屏回答：玩家要看什么、可做什么、代价是什么、如何撤销。折叠的是帮助与重复说明，不能折叠唯一的风险、当前战术选择或撤退二次确认。所有改动保持现有引擎与存档边界。
