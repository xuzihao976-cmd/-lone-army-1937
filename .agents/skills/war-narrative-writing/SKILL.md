# 《孤军》战争叙事与对白编辑

## 已确认的创作方向

写实惨烈，可以有具体伤势、死亡、粗口和战地创伤，避免猎奇。尊重真实人物和历史事件的边界；新增的私人回忆、情感与内心戏主要属于虚构士兵。用户当前明确要求优先于本文。

## 编辑的四个问题

1. 谁在说话，他此刻想让对方做什么，或者不愿承认什么？
2. 他能看到、听到、知道什么？这与侦察、名册、资源和楼层状态是否一致？
3. 这句台词如何通过动作、停顿、物件或措辞表现处境，而不是直接替人物宣布情绪？
4. 玩家需要从这段话获得什么：气氛、人物关系、风险说明，还是已发生的结算？不要混淆用途。

## 文本与状态的契约

- 普通对话可以描写说话、姿态、想念、恐惧、沉默与尚未实施的愿望；不能宣称新伤亡、治疗成功、获得物资、开火、侦察完成或时间已经推进。
- 通用敌袭开场只写来袭的感受与反应，不预支守军死亡、杀敌或武器消耗。伤势、阵亡和具体战果仅放入已有结算成立的分支。
- 有死亡依据可以描写失去生命的过程与他人反应；没有数量依据不能新增“一整班”“又倒下几个”等事实。
- 不让已经阵亡的具名人物无条件开口。通用台词优先使用副官、老兵、班长等角色称谓；涉及名册人物先读取实际状态。
- 不泄露未侦察目标，不把名册死者数当全军阵亡数，不把战斗伤亡等同于全部死亡。
- 数字、时间、物资变化与风险来自引擎计算。上限截断时报告实际变化，不能把“最多增加15”写成无条件增加15。
- 保留模板占位符、命令字符串、事件与卡片标识、前置条件、规则数值和随机调用顺序。
- 对白轮换属于展示记忆，不使用战斗 RNG，不新增资源或改变战役难度。

## 人物声音

- 副官：短、准、收着说；关心通常落在一个具体安排上。不当讲解界面的客服。
- 老兵与班长：粗粝、务实，可以有干涩笑话；嘴硬与害怕可以同时存在，不句句慷慨陈词。
- 传令兵：急切而认真，想把话说清、怕漏事；不用幼童化语言，也不捏造新军情。
- 军医：注意呼吸、体温、手和药箱；承认救治的限度，不把痛苦写成漂亮修辞。
- 叙述者：靠近现场，少下价值判词。让人物的迟疑、选择和后果承担情感。

## 强度、节奏与尺度

- 惨烈来自损失的代价和无法轻易补回的生活，不来自连续堆叠断肢、内脏和尖叫。
- 伤势描写须服务于一名具体处境中的人；避免把所有伤员都写成同一种严重损伤。
- 为沉默、家常、笨拙的关照和黑色幽默留位置。持续高亢与持续绝望都会让长线游戏麻木。
- 每条普通回应通常一至三句，适合手机阅读；战报先给场景，再给清晰结算，规则说明不写成散文。
- 避免现代网络腔、术语穿帮、动物化敌军、空洞口号、反复的“目光坚定”和统一格式的煽情结尾。
- 不给历史人物虚构私人心理或署名引语。游戏中的可变日期、伤亡和结局不能冒充逐刻重现的史实。

## 整库工作流

1. 盘点数据文本、引擎内联叙述、事件后果、结局与界面提示，检查所有调用位置和成立条件。
2. 先统一角色声音和状态契约，再逐组手写；同一主题内变换回应意图和节奏，不只换同义词。
3. 对比规则说明、按钮、行动预览和实际后果；明确哪些是“尚未执行”“最多获得”与“本次实际变化”。
4. 审核每个带伤亡、战果、物资或历史断言的句子，找不到代码依据则改写或移到有依据的分支。
5. 运行项目检查和必要模拟，确认文本变化没有改变结算、随机数、存档或军令边界。
6. 在叙事指南和交接中记录尺度、覆盖范围、实际验证、提交以及尚未部署或未实测的部分。

## 专业编辑如何取舍

先守住叙事事实，再选择视角，最后打磨句子。一个很好的句子如果会让玩家误判战况，也必须删改。用“把药瓶倒过来，瓶底只碰出一声轻响”承接已确认缺药的状态；不要用“军医又救活三个人”装饰普通聊天。将动作参考 Skill 的因果原则用于战斗感受，不把战报变成现实伤害教程。
