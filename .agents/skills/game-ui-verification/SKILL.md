# 《孤军》界面验收与参考核验

先读 AGENTS.md、本次 diff 与 UI-DESIGN.md。本 Skill 不声称已安装浏览器插件；使用当前环境真实可用的浏览器工具或项目自动化。

## 参考资料

- 优先作者官网、官方 press kit、开发日志和发行商店截图。记录网址、作者／团队、原始发行时间、访问日期及本次实际看过的画面。
- 查不到正文、403或仅找到入口时，如实记录，不能引用其未读内容。早期发行和署名可支持“有人类作者的已发行作品”，不能证明今日每个网页资产的全制作链均无AI。
- 不用AI生成图、无来源聚合图和仿作充当人工原作；不把网上可查看等同于可复制商用。第三方图片只作审查，游戏内不嵌入。

## 浏览器验收

1. 先捕获基线，再检查320×640、390×844、768×1024、1280×900；补充短屏／横屏及浏览器字体放大。区分“尺寸模拟”和“真人手机”。
2. 检查选关、开始／继续、战术选择、教学、聊天、长预览、地图、顾问、事件、存取档和结局。每项记录实际执行，不能把未覆盖流程写成通过。
3. 验证文档横向溢出、主按钮边界、触控尺寸、嵌套滚动、焦点轮廓、文字对比度及减少动态效果。
4. 对查询、预览、顾问和取消，比较前后完整GameStats；AI关闭时记录模型请求为0。纯展示改动不得改动战斗、时间、资源、RNG或存档字段。
5. 执行npm run check。只有规则／命令／存档行为涉及变更时追加规定模拟；不要为纯样式改动伪造新的模拟结果。
6. 将截图、检查结果与限制写入交接；代码完成、测试、分支推送、main合并、部署和线上实测分别说明。

美学判断给出原因与可见对比，不给未经统计的百分比。页面可运行也不代表真实模型已连接。
