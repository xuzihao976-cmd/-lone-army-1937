# 《孤军》音乐与声音试映

解压后在浏览器打开 index.html。也可单独播放每套的 demo.mp3。三段混合试听使用相同的剧情顺序和音效入点。选择作品方向后再决定正式游戏的加载、静音、音量与触发规则。

| 方向 | 音乐语言与声场 | 需要判断的取舍 |
|---|---|---|
| A 灯下的名册 | 三拍，钢琴、大提琴、单簧管与弦乐组。木质接触声近，空间尾音短。主句先上行一步，再向下回应。 | 名册与仓库最贴近“守夜档案”。桥头的紧张主要靠节奏，压迫感较含蓄。 |
| B 江岸来信 | 复合拍感，以五声音阶、尼龙弦吉他、长笛、拨弦与中提琴构成。操作声偏轻，纸布摩擦较清晰。 | 适合陪伴寻人和护送。旋律存在感较强，连续阅读时应试听是否分心。属于当代游戏配乐创作。 |
| C 墙内的回声 | 五拍，低音管、颤音琴、低音提琴与拨弦。半音摩擦、错开的重音和较长的反射塑造封闭空间。 | 危机段辨识度高。低声部在小音箱上可能变薄，整章使用也可能使玩家疲劳。 |

每套含名册、街巷、桥头、仓内四条循环与一条一次性收束。每类反馈有三种声音。受击 1/2/3 分别供轻、中、重结果使用，其余是力度相近的替代版本。远爆作为事件声音独立存放，阶段完成使用短音型。正式接入时建议在结算确认后给对应反馈，逐字声做频率限制，长期朗读和重复进入菜单时保持安静。不要从试听里的响声推断实际游戏伤亡。

## 重建

在 Linux 安装 Python、NumPy、SciPy、libfluidsynth 3、FFmpeg 与 TimGM6mb。运行 python render.py。可通过 SOUNDFONT 指向本地 SF2。使用不同采样库将改变最终音色。配乐作曲、编配、音效与混音均在 render.py 中定义，随机变化使用固定种子。

乐器使用 TimGM6mb 采样音色库（Tim Brechbill、David Bolton，Debian 软件包 timgm6mb-soundfont，GPL-2）；未附音色库。音效采用滤波噪声、材质共振和早期反射合成。没有采用战地录音或第三方游戏音乐。音频为 32 kHz 双声道，配乐 Ogg Vorbis，独立音效 PCM WAV，比较用混音 MP3。
